# Arc Dash

Phaser cube-runner: you move forward on your own, tap to jump, restart on a spike. Inspired by Geometry Dash cube mode; original course, art, and beat.

```bash
pnpm --filter @fzgame-arcade/arc-dash dev
```

Open [http://127.0.0.1:3401](http://127.0.0.1:3401).

| Input | Action |
| --- | --- |
| Tap / click / space / ↑ | Jump (or ship-boost on pads) |
| P | Pause |

Editor config: speed, accent, mute.
