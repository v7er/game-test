# Tentris

Ten-column falling-block puzzle for GameHub.

```bash
pnpm --filter @fzgame-arcade/tentris dev
```

Open [http://127.0.0.1:3400](http://127.0.0.1:3400).

| Key | Action |
| --- | --- |
| ← → | Move |
| ↓ | Soft drop |
| Space | Hard drop |
| Z / X or ↑ | Rotate |
| P | Pause |

Editor config: start level, accent color, ghost piece.
